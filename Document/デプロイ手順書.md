# デプロイスクリプト deploy.sh
このスクリプトは、AWS SAMを使ったデプロイ作業を簡素化するために使用されます。  
環境変数を定義した .tune-env ファイルを読み込み、SAMビルドとデプロイを実行します。

## 前提条件
AWS CLIがインストールされ、適切に設定されていること。  
AWS SAM CLIがインストールされていること。  
expectコマンドがインストールされていること（自動応答オプションを使用する場合）。  

## スクリプトの内容
環境変数を .tune-env ファイルから読み込みます。  
読み込んだ環境変数を使ってSAMビルドとデプロイを行います。  
デプロイ時に自動応答オプション（-y）を使用することで、自動的にデプロイを承認します。  

## .tune-env.exampleファイルの作成
デプロイに必要な環境変数の雛形を .tune-env.example ファイルに記述し、GitHubで管理します。

### 例
```sh
# .tune-env.example
HOGELAMBDA="HelloEnv"
FOOBAR="AnotherValue"
API_URL="https://example.com/api?param=value&other=value"
```
各行に KEY=VALUE の形式で記述します。  
URL形式の値は必ずクオートで囲みます。  

## .tune-envファイルの作成
.tune-env.example ファイルをコピーして`.tune-env`として保存し、各自のローカル環境で管理します。

```sh
cp .tune-env.example .tune-env
```

## deploy.sh の使用方法
`.tune-env`ファイルを作成し、デプロイに必要な環境変数を設定します。  
`deploy.sh`スクリプトを実行します。  

### 通常のデプロイ
```sh
./deploy.sh
```

### 自動応答オプション付きデプロイ
自動応答オプション（-y）を使用することで、プロンプトに自動的に`y`を入力してデプロイを進めます。  

```sh
./deploy.sh -y
```

## 例外処理
`.tune-env`ファイルに設定したキーと値のペアが正しくない場合、スクリプトは適切にエラーメッセージを表示します。  
SAMデプロイ時にエラーが発生した場合は、標準エラーログに記録されます。  

## 注意点
`.tune-env`ファイルには、セキュリティ上の理由から機密情報を含めないでください。  
機密情報を含む場合は、適切な権限管理とファイル保護を行ってください。
